# payment-rules-engine
Payment Rules Processor é um componente de autorização e processamento de pagamentos em Java, projetado para simular o comportamento de um gateway financeiro. O projeto demonstra a aplicação prática de conceitos de Orientação a Objetos (POO), Polimorfismo, Encapsulamento e Tratamento Defensivo de Erros utilizando Exceções Customizadas de Negócio.
